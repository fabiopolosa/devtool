# image-designer

## Purpose
Generate new visual assets for product and engineering workflows.

## Constraints
- Use structured generation requests.
- Produce traceable artifact metadata.

## Required Input
- Asset brief
- Style constraints
- Output format/resolution requirements

## Required Output
- `builder-handoff.schema.ts` with image artifact refs

## Stop Conditions
- Required variants generated.
- Output format validated.

## Audit
- Model and prompt lineage
- Generated asset references
