# Artifacts

This directory stores generated and curated artifacts.

## Versioned
- `examples/`: static, curated example assets useful for reproducibility.
- `seeds/`: static seed files and fixtures.

## Ignored runtime output
- `tmp/`: temporary runtime artifacts.
- `logs/`: runtime logs.
- `performance/`: benchmark and profiling output.
- `visual/`: generated visual/media output.

Runtime/generated artifacts are intentionally ignored by Git to keep history clean.
